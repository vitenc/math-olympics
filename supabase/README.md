# Облако: аккаунты и синхронизация (Supabase)

Без облака тренажёр работает как раньше: прогресс живёт в браузере, аккаунтов
нет. Облако добавляет:

- **вход взрослого** (родителя или учителя) по шестизначному коду из письма, без пароля;
- **профили учеников** — псевдоним, класс, отметка о согласии; у ребёнка нет ни почты, ни аккаунта;
- **синхронизацию**: прогресс ученика одинаковый на планшете в классе и на компьютере дома;
- **классы**: учитель создаёт класс, родитель записывает ребёнка по коду;
- **панель учителя** (`teacher.html`) и отчёт «до и после» по любому ученику класса.

## Как включить (15 минут)

1. Зарегистрироваться на [supabase.com](https://supabase.com) и создать проект.
   Регион — ближайший к пользователям (для ОАЭ и Саудовской Аравии — Middle East,
   если доступен, иначе Frankfurt).
2. **SQL Editor** → вставить `supabase/schema.sql` целиком → **Run**.
   Файл можно запускать повторно — например, после обновления схемы.
3. **Authentication → Providers → Email**: включён. **Confirm email** — включено.
4. **Authentication → Email Templates → Magic Link**: в текст письма добавить код,
   иначе придёт только ссылка, а тренажёру нужен код (ссылка не работает
   ни с `file://`, ни в Android-приложении):

   ```html
   <h2>Код для входа</h2>
   <p>Ваш код: <b style="font-size:24px">{{ .Token }}</b></p>
   <p>Если вы не входили в Olympiad Sprint, просто удалите это письмо.</p>
   ```

5. **Authentication → URL Configuration → Site URL**: адрес сайта на GitHub Pages
   (`https://<user>.github.io/math-olympics/`).
6. **Project Settings → API**: скопировать **Project URL** и **anon public** key в
   `assets/cloud-config.js`, закоммитить.

anon key публичный: он виден любому посетителю сайта, а данные защищают правила
доступа из `schema.sql`. **Ключ `service_role` никогда не класть в репозиторий** —
он обходит все правила.

Бесплатного тарифа Supabase хватает на пилот: письма со встроенного почтового
сервиса ограничены несколькими в час, поэтому для класса из 20+ семей
подключите свой SMTP (**Project Settings → Auth → SMTP**) — например, Resend
или SendGrid.

## Что где хранится

| Таблица | Что | Кто видит |
|---|---|---|
| `profiles` | роль взрослого, имя (необязательно), когда принял условия | только сам взрослый |
| `students` | псевдоним, класс, кем и когда дано согласие | владелец; учитель класса — только чтение |
| `classes` | название, код для входа | учитель |
| `class_members` | кто в каком классе | учитель класса и владелец ученика |
| `kv` | прогресс ученика: ключ localStorage → значение | владелец; учитель класса — только чтение |

Удаление ученика удаляет и его прогресс, и членство в классах. На странице
аккаунта у каждого профиля есть кнопки «Скачать данные» и «Удалить».

## Как устроена синхронизация

- У выбранного ученика на устройстве свои ключи: `st.<id>.sasmo.progress` и т. д.
  Поэтому на одном планшете могут заниматься несколько детей.
- Каждая запись движка помечает ключ изменённым; через 1,5 секунды он уходит в `kv`.
  Уходя со страницы, недосланное отправляется сразу.
- При открытии страницы изменения из облака подтягиваются. Если оба устройства
  меняли прогресс, он **сводится**: по каждому дню побеждает пройденный, затем
  более поздний, затем тот, где больше ответов; журналы ошибок объединяются.
- Время записи ставит сервер — часы планшета могут врать.

## Проверки

```
node build/cloudtest.js      # клиент против имитации Supabase (нужен jsdom)
sh tools/test_rls.sh         # правила доступа на настоящем PostgreSQL
```

`tools/test_rls.sh` поднимает временную базу на порту 5499 (нужен запущенный
PostgreSQL; `PGHOST`/`PGPORT` можно переопределить), применяет `schema.sql`
поверх имитации окружения Supabase (`test_shim.sql`) и проверяет, что чужой
родитель ничего не видит, учитель видит только свой класс и только читает,
вход в класс идёт по коду, удаление каскадное, аноним не видит ничего.

## Чего ещё нет

- Юридической проверки: тексты согласия — черновик. Перед пилотом в ОАЭ и KSA
  их должен посмотреть юрист (PDPL, закон ОАЭ о защите данных).
- Хостинга данных в регионе: зависит от доступных регионов Supabase.
- Недельного дайджеста родителю по почте.
