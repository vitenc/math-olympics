# CLAUDE.md

Контекст для Claude Code. Подробное устройство тренажёра — в [README.md](README.md);
здесь только то, что нужно знать до первой правки.

## Что это

Тренажёр подготовки детей 2–3 класса к математическим олимпиадам (SASMO и
другие): программа на 28 дней, пробные экзамены, журнал ошибок, прошлые
олимпиады целиком, теория «Мне непонятно — объясни», таблица умножения на
скорость. Чистый HTML/JS без фреймворков и без сборки зависимостей; всё
работает по `file://`, двойным кликом по `index.html`.

Интерфейс и задачи — на русском. Отвечать пользователю и писать коммиты —
тоже по-русски.

## Цель проекта (с сентября 2026)

Превратить тренажёр в трёхъязычную (EN/AR/RU) платформу K-6 для школ ОАЭ и
Саудовской Аравии и получить безвозмездное финансирование (Hub71, NTDP,
Mawhiba, WISE). Масштаб «XL», план — в [ПЛАН-XL.md](ПЛАН-XL.md) (потоки
W1–W7, календарь на 12 месяцев, пилот на 60 детей, чек-лист P1–P8).

Доказательство идеи пока n=2 (сын автора и его друг, 2 класс, золото и
серебро SASMO после программы). Три риска, которые надо закрыть до заявки:

- название SASMO в продукте — нужен свой бренд («Olympiad Sprint» —
  рабочая заглушка);
- чужой контент в репозитории (буклет MathXCEL 2024, тест Copernicus);
- доказательная база из двух детей.

При выборе задач предпочитать то, что добавляет измеримость (отчёт до/после,
аккаунты) и английский интерфейс, а не новые фичи.

## Команды

```
node build/check.js           # после правки задач: структура, ответы, теория
node build/build.js           # пересобрать sasmo-month.html и sasmo-month-2.html
npm install --no-save jsdom   # один раз
node build/uitest.js          # после правки движка или вёрстки
pip install -r tools/requirements.txt
python tools/verify.py        # пересчитать ответы через sympy
```

`package.json` нет — jsdom ставится разово и в репозиторий не попадает.

## Где что

- `index.html` — хаб; `index.html?g=2` — второй класс. Прогресс классов
  хранится раздельно (localStorage), смешивать нельзя.
- `data/dayNN.js`, `data/examN.js` — 3 класс; `data/g2/` — 2 класс
  (переменные с приставкой `G2`).
- `data/sasmo2*.js`, `data/amo2*.js`, `data/fmo22.js`, `data/mathxcel24.js` —
  прошлые олимпиады; каталог работ — `window.PAPERS` в `assets/paper.js`,
  страница — `paper.html?p=<id>`.
- `assets/quiz.js` — движок; `assets/theory.js` — теория по темам.
- `src/` — исходные буклеты олимпиад (PDF/DOCX).
- `android/` — приложение Math Gate (`com.mathgate`).

## Подводные камни

- **Движок в двух местах.** `sasmo-month.html` собирается из
  `build/template.html` со своей копией движка, не из `assets/quiz.js`.
  Правку поведения вносить в оба места; `build/uitest.js` проверяет обе.
- **Счёт секционный.** `rulesFor` в `assets/quiz.js` берёт
  `rules.sections` — список секций с ценой задачи (SASMO — две, AMO — три:
  1–15 по 3, 16–20 по 5, 21–25 по 6; FMO — четыре части, штраф −10 только в
  №21). Старая запись `split` + `a`/`b` тоже понимается. Проверки —
  разделы 12 и 13 в `build/uitest.js`.
- **Задачи без ответа** помечены `skip` и в счёт не идут: SASMO 2024 №13 и
  №25, SASMO 2023 №6. Если найдутся ключи — убрать `skip`, дописать `ans`,
  `hint`, `ex` и поправить `max` в каталоге.
- `build/check.js` падает, если у задачи не нашлась теория — новую тему
  надо добавить в `assets/theory.js`.
- **Извлечение из буклетов:** `pdftotext` теряет кириллицу, PyMuPDF (`fitz`)
  — нет. Рисунки брать через fitz по xref в `img/<олимпиада>/<год>/qNN.png`.
  У FMO фон страниц — картинки на всю страницу; перед вырезкой удалять их
  (`page.delete_image`), иначе лезут линейки.
- `img/q1…q25.png` в корне используются `assets/quiz.js` — не удалять.

## Android

Версия 2.0 — только обучение: WebView всего сайта, отдаётся офлайн из assets
по `https://appassets.androidplatform.net/`; файлы копируются из корня
репозитория при каждой сборке. Замок телефона, служба спецвозможностей,
device admin и экран родителя из версии 1 убраны — их код в коммите
`8ab3d55`. Когда попросят вернуть блокировку — начинать оттуда и сохранить
тот же `applicationId`.

Сборка: `cd android && ./gradlew assembleDebug`. Нужен JDK 17–21: с JDK 25+
Gradle 8.9 не стартует (локально — `JAVA_HOME` на `jbr` из Android Studio).
