# Картинки к задачам

Почти все рисунки тренажёр **рисует сам** — это не файлы, а векторная графика,
которую собирает `assets/fig.js`. Такой рисунок не мылится на планшете,
подстраивается под тёмную тему, ничего не весит и одинаково работает в
многостраничной версии, в одностраничной `sasmo-month.html` и на `file://`.

Если какой-то картинки в наборе не хватает — сначала посмотрите каталог фигур
ниже: скорее всего, нужная там уже есть. Готовые иллюстрации (растр) нужны
только там, где схемой не обойтись; для них есть папка и промпты в конце файла.

## Как добавить рисунок к задаче

У задачи три необязательных поля:

```js
{ type: 'mcq', topic: 'Счёт фигур',
  fig:   'grid:3,3',            // рисунок к условию — виден сразу
  q:     'Квадрат разделён на сетку 3 на 3 клетки. Сколько всего квадратов?',
  opts:  ['9', '13', '14', '15'], ans: 2,
  hint:  'Кроме девяти клеток есть квадраты 2×2 и один большой.',
  exfig: 'grid:3,3',            // рисунок к разбору — виден вместе с ответом
  ex:    'Всего 9 + 4 + 1 = <b>14</b>.' }
```

| Поле | Когда показывается | Зачем |
|---|---|---|
| `fig` | сразу, под условием | задача **описывает** рисунок: «на этом рисунке», «сколько квадратов» |
| `exfig` | вместе с разбором | схема, которая **подсказывает решение**: полоски, круги Эйлера, весы |
| `img` | сразу, под условием | обычная картинка файлом, см. последний раздел |

Правило простое: если рисунок выдаёт ход решения — ему место в `exfig`, а не в
`fig`. На самой олимпиаде подсказок в условии не будет.

После правки данных пересоберите одностраничные версии (обоих классов):

```
node build/check.js      # проверка наборов
node build/build.js      # сборка
```

## Каталог фигур

| Спецификация | Что рисует |
|---|---|
| `grid:3,3` | прямоугольник, разбитый на 3 столбца и 3 ряда (`grid:4,1` — полоска) |
| `tri:3` | треугольник, разрезанный из вершины на 3 маленьких |
| `points:4` | точки на прямой — к задачам «сколько отрезков» |
| `dots:1,4,9,?` | ряд фигур из точек: квадраты 1×1, 2×2, 3×3 и «?» |
| `triangles:1,3,6,10,?` | то же для треугольных чисел |
| `tristrip:3` | треугольники в ряд с общими сторонами (из палочек) |
| `stairs:3,2,1` | лесенка из клеток, числа — высоты столбцов |
| `steprect:12 см,8 см` | ступенчатая фигура внутри описанного прямоугольника |
| `rect:9 см,?` | прямоугольник с подписями нижней и правой стороны |
| `segment:5,3,27 см` | отрезок из 5 долей, первые 3 охвачены скобкой |
| `parts:74,38,?` | модель «часть–целое»: целое над полоской, части внутри |
| `bars:Ваня=1;Петя=3;@total=48` | модельный метод: полоски из долей |
| `bars:Катя=1;Оля=1+12;@total=40` | то же, но у Оли доля **плюс подписанная разница** |
| `bars:B=1;A=5;@diff=32` | скобка над «лишними» долями — модель разницы |
| `balance:2 яблока,6 слив` | чашечные весы в равновесии |
| `euler:25,15,12,5,футбол,плавание` | круги Эйлера: всего, A, B, оба и подписи |
| `posts:100,10` | столбы вдоль дороги: их на один больше интервалов |
| `log:5` | бревно, распиленное на 5 частей |
| `floors:4` | этажи и пролёты между ними |
| `clockstrike:6` | удары часов и промежутки между ними |
| `paths:2,2` | сетка маршрутов со стартом и финишем |
| `cube` | один куб |
| `cubes:3` | большой куб 3×3×3 из маленьких |
| `tower:4,3,2,1` | башня слоями, числа — сторона слоя снизу вверх |
| `box:3,2,2` | кубики, плотно уложенные в коробку |
| `sym:tri,square,penta,circle` | фигуры с показанными осями симметрии |

Аргументы разделяются запятыми, поэтому **запятых внутри подписей быть не
должно**. У `bars` части разделяются точкой с запятой.

Проверить новую фигуру, ничего не пересобирая:

```js
node -e "global.window={}; require('./assets/fig.js'); console.log(window.SASMO_FIG.build('grid:3,3'))"
```

## Готовые картинки файлом

Если нужна настоящая иллюстрация, а не схема:

1. Положите файл в **`img/sasmo/`** — например `img/sasmo/day09-piramida-sharov.png`.
   Промпты ниже написаны под третий класс, но поле `img` одинаково работает
   и в наборах второго класса (`data/g2/`).
2. Добавьте задаче поле `img` с путём от корня репозитория:

```js
{ type: 'open', topic: 'Фигурные последовательности',
  img: 'img/sasmo/day09-piramida-sharov.png',
  q: 'Пирамиду складывают из шаров…', ans: 36, … }
```

3. Пересоберите: `node build/build.js`. Сборка сама переведёт картинку в
   `data:`-строку и вложит внутрь `sasmo-month.html`, чтобы страница осталась
   одним файлом. Если файла нет, сборка честно об этом скажет и не упадёт.

Требования к картинкам: **белый фон** (на тёмной теме она смотрится как
наклеенная фотография, это нормально), ширина 1000–1400 px, без подписей
мелким шрифтом — ребёнок читает условие в тексте, картинка только показывает.

### Промпты

Это места, где схемой не обойтись, а иллюстрация помогла бы. Тренажёр работает
и без них — все эти задачи решаются по тексту.

Общая приставка к каждому промпту:

> outlines (#24497f) on a plain white background, soft muted fills, no text,
> no shadows, no gradients, centred composition, wide 3:2 frame.

шаров: в верхнем слое 1 шар, в каждом следующем на 2 шара больше».

> rows, from the top down 1, 3, 5, 7, 9 and 11 balls, each row centred under
