# Журнал прогресса в Google Таблице

Прогресс детей хранится в браузере того устройства, на котором они
занимаются. Журнал позволяет взрослому видеть его со своего устройства:
после каждого законченного набора задач (день программы, экзамен, замер,
олимпиада) тренажёр отправляет строку в вашу Google Таблицу. Отчёт
открывается по постоянной ссылке.

Без облака, без аккаунтов и без входа у детей. Пока в
`assets/log-config.js` нет адреса, тренажёр ничего не отправляет.

## Как включить (5 минут)

1. Создать новую Google Таблицу, например «Прогресс Olympiad Sprint».
2. **Расширения → Apps Script**. Удалить всё в `Code.gs` и вставить
   содержимое `tools/progress-sheet/Code.gs`. Сохранить.
3. **Настройки проекта** (шестерёнка слева) → **Свойства скрипта** →
   добавить свойство `REPORT_KEY` с любым длинным секретным словом, например
   `dima-bogdan-7f3k9q`. Без него отчёт не откроется.
4. **Развернуть → Новое развёртывание** → тип **Веб-приложение**:
   - «Запуск от имени» — **Я**;
   - «У кого есть доступ» — **Все**.

   Нажать **Развернуть** и разрешить доступ к таблице (Google предупредит,
   что приложение не проверено: **Дополнительно → Перейти**).
5. Скопировать адрес веб-приложения (`https://script.google.com/macros/s/…/exec`)
   и вписать его в `assets/log-config.js` (поле `url`), закоммитить и
   пересобрать (`node build/build.js`). Или прислать адрес Claude.

## Где смотреть

- **Отчёт:** `<адрес …/exec>?key=<REPORT_KEY>` — в закладки. Вверху —
  переключатель учеников и периода (7 дней, 30 дней, всё время); работает
  без перезагрузки.
  - «Все» — карточка на каждого ребёнка: когда занимался (красным, если
    перерыв от 3 дней), серия дней, наборы и процент верных, календарь.
  - Ученик — серия и рекорд, точность и время; календарь занятий за
    16 недель; точность по дням; темы, в которых больше всего ошибок;
    лучший результат по каждой олимпиаде и экзамену; журнал по дням с
    фильтром «Программа / Экзамены / Олимпиады / Замер» и номерами задач
    с ошибками.
  - `…&who=Дима` открывает сразу ученика.
- **Таблица:** лист «Журнал», одна строка на законченный набор. Её можно
  фильтровать и строить по ней графики.

## Кто есть кто

- **Олимпиады прошлых лет** (`paper.html`) уходят под именем, выбранным на
  странице работы (Дима / Богдан).
- **Программа, замер и журнал ошибок** привязаны к устройству. При первом
  открытии хаба тренажёр спросит: «Кто занимается на этом устройстве?».
  Имя можно сменить на хабе ссылкой «сменить».

## Что стоит знать

- Незаконченный набор тоже виден: каждые 5 ответов тренажёр обновляет
  строку попытки (статус «в процессе»), а в конце — ставит «закончен».
  Одна попытка — одна строка. В отчёте такая строка помечена «не закончен ·
  решено 10 из 25» и не входит в счётчик законченных наборов.
- Нет интернета — строка ждёт на устройстве и уходит при следующем
  открытии любой страницы тренажёра.
- Уходит только итог набора: имя, класс, набор, верно/ошибок, баллы,
  время и номера задач с ошибками. Ни почты, ни других данных ребёнка нет.
- Адрес веб-приложения лежит в публичном репозитории, поэтому дописать
  строку в журнал может кто угодно. Смотреть отчёт без `REPORT_KEY`
  нельзя. Если кто-то начнёт засорять журнал, сделайте новое развёртывание
  и обновите адрес.
- После правки `Code.gs` нужно **Развернуть → Управление развёртываниями →
  изменить → Новая версия**. Тогда адрес останется прежним.
